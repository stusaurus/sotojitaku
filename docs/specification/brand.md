# SOTOJITAKU Brand Direction

## Brand
**SOTOJITAKU（ソトジタク）**

Brand copy: **外へ行く準備を、もっと楽しく。**  
First service: **SOTOJITAKU CAMP**  
Service copy: **はじめてのキャンプを、あなた仕立てに。**

## Positioning
「アウトドア用品比較サイト」ではなく、外遊びを始めたい人のための準備サービス。実店舗の上質なアウトドア専門店で相談しながら自分の休日を組み立てる感覚をオンライン化する。

## Visual direction
**上質なアウトドア専門誌 × セレクトショップ × 休日の体験サービス**

### Keywords
- 上質
- 自然
- 暖かい
- 静かな冒険感
- 大人にも似合う
- 初心者にやさしい
- 余白がある
- 商品より体験が主役

### Avoid
- 安っぽいCSS図形をメインビジュアルにする
- 教材サイト風
- 子ども向けすぎるイラスト
- 商品カードだらけのEC風トップ
- 原色を大量使用
- 「激安」「最安」を前面に出す
- 装飾を足しすぎる

## Hero
スマホ最上部からビジュアルを大きく使う。空・木・キャンプサイトの余白の中へコピーを溶け込ませる。

Main: **はじめてのキャンプを、あなた仕立てに。**
CTA: **キャンプをつくる**

## Visual system
- 背景: 生成り〜自然光を感じるニュートラル
- 主役: 森の深さを感じる落ち着いたグリーン系
- Accent: 焚き火・夕暮れを連想する暖色を限定的に
- 色コードは実装時にアクセシビリティ確認後確定。固定色を先に決めすぎない。
- 写真/生成ビジュアルは統一したアートディレクションで制作。
- 人物を使う場合、広告的なポーズより「休日の瞬間」を優先。

## Typography
- 日本語本文は可読性最優先
- ブランドロゴは英字 SOTOJITAKU を主役
- 見出しは編集誌的な大きさと余白
- 文字数を抑え、ビジュアル内に自然に置く

## UI personality
「診断フォーム」ではなく「自分のキャンプができていく」。選択のたびに上部のキャンプサイトが完成していく。
