# Responsive Rules

## Mobile first
Primary design width: 390px-class smartphones.

### Mobile
- gutter 20px
- hero 90–100svh
- question visual 55–60vh相当
- touch target >= 44px
- horizontal scroll 0
- product card 1 column

### Tablet
- content max-width ~760–880px
- simulator visual and sheet may become 60/40 split vertically or 55/45 side-by-side only if readability improves

### Desktop
- max content width 1200–1280px
- hero uses full-bleed imagery
- simulator may use left visual / right question panel
- keep editorial whitespace; do not stretch cards to fill the screen

## Breakpoint intent
Breakpoints are implementation details, not visual goals.
Do not create a separate “desktop design language”.
