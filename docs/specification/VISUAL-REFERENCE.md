# SOTOJITAKU Visual Source of Truth

The images in `visual-references/` are not loose inspiration.
They are the visual acceptance baseline for the first implementation.

## Priority reference 1
`a_wide_cinematic_split_screen_outdoor_camp_scene.png`

Use this to preserve:
- the before → after emotional transformation
- premium editorial outdoor atmosphere
- identical-place continuity
- morning → dusk transition
- quiet, cinematic color treatment
- the feeling that the user's choices build the campsite

Do NOT literally copy the split-screen layout into the product.
The product should recreate the transformation through interaction.

## Priority reference 2
`a_wide_high_quality_ui_design_mockup_collage_of_a.png`

Use this to preserve:
- mobile-first composition
- image-led hero
- restrained typography
- premium cream / forest / ember palette
- Q6 experience tiles
- completion screen hierarchy
- product recommendation cards that remain editorial, not marketplace-like
- bottom navigation simplicity
- generous whitespace
- calm button styling

## Non-negotiable screens
The following screens must visually feel at least as intentional as the reference mockup:
1. Home
2. Q6 「何をしたい？」
3. Completion 「キャンプ、できた。」
4. Product recommendations

If the implementation feels more generic than the reference,
do not continue polishing lower-priority screens.
Redesign these first.

## Visual hierarchy
1. Experience / scene
2. User's completed camp
3. Why the recommendation fits
4. Product
5. Price

## Failure modes
Reject any version that looks like:
- a Rakuten affiliate list
- a generic price comparison site
- a generic camping blog
- a SaaS questionnaire
- a card-heavy dashboard
- a cheap illustrated camping app
- a children's learning site

## Final visual test
Show the Home, Q6, Completion and Product Recommendation screens side by side with the reference image.
Ask:
“Would a user still feel this is fun to prepare for camping?”

If the answer is no, the design is not ready.
